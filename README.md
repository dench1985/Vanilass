# Каталог товаров

Учебный проект на JavaScript для отображения и поиска товаров.

## Возможности

- Загрузка списка товаров через Fetch API
- Фильтрация по названию и бренду
- Поиск по части слова без учёта регистра
- Фильтрация по цене
- Постраничное отображение товаров
- Демонстрационные товары, если API недоступен
- Сообщение, если подходящие товары не найдены

## Технологии

HTML, CSS, JavaScript, Fetch API, DOM

## Запуск

Откройте файл `index.html` в браузере.

При недоступности API проект отображает демонстрационные товары.

Проект выполнен в учебных целях с поддержкой наставника.
